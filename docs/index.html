API Documentation

TOENK is fully compatible with the OpenAI client SDK. Change one line and go.

Quickstart

Install the OpenAI Python SDK and point base_url to TOENK:

# Install
pip install openai

# Use TOENK
from openai import OpenAI

client = OpenAI(
    base_url="https://api.toenk-api.com/v1",
    api_key="sk-your-key-here"
)

response = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)

Authentication

Include your API key in the Authorization header as a Bearer token:

Authorization: Bearer sk-your-api-key

Get your key at toenk-api.com/sign-in. Keep it secret — don't expose it in client-side code or public repos.

Chat Completions

TOENK supports the full OpenAI Chat Completions API:

POST /v1/chat/completions

Create a chat completion. Supports text, multi-turn conversation, and vision-capable models.

Request Body

ParameterTypeRequiredDescription
modelstringYesModel ID, e.g. deepseek-v4-flash, gpt-4o
messagesarrayYesArray of message objects with role and content
temperaturenumberNo0-2. Higher = more random. Default: 0.7
max_tokensintegerNoMaximum tokens to generate
streambooleanNoEnable token-by-token streaming. Default: false
top_pnumberNoNucleus sampling. Default: 1

Example Response

{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "model": "deepseek-v4-flash",
  "choices": [{
    "index": 0,
    "message": {
      "role": "assistant",
      "content": "Hello! How can I help you today?"
    },
    "finish_reason": "stop"
  }],
  "usage": {
    "prompt_tokens": 15,
    "completion_tokens": 9,
    "total_tokens": 24
  }
}

List Models

GET /v1/models

Returns all available models with pricing and context window info.

Example (cURL)

curl https://api.toenk-api.com/v1/models \
  -H "Authorization: Bearer sk-your-key"

See Models page for the full catalog with pricing.

Streaming

Enable streaming with stream: true. Responses arrive as Server-Sent Events (SSE):

stream = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "Tell me a story"}],
    stream=True
)
for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")

Error Handling

CodeMeaning
400Bad request — check your parameters
401Invalid or missing API key
429Rate limit exceeded. Retry with backoff.
500TOENK internal error. Contact support.
503Service unavailable. Temporary outage.
